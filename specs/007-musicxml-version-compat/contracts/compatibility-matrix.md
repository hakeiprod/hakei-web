# Compatibility Matrix: MusicXML 2.0 / 3.0 / 3.1 / 4.0

これは実装時の受入・検証基準。現時点の対応完了報告ではない。対象版を許可することと、各版の全要素を表示・演奏することは異なる。

| ---------- | -------------------- | -------------- | -------------- | -------- |
| 2.0        | 対応対象             | 対応対象       | score-partwise | 2.0      |
| 3.0        | 対応対象             | 対応対象       | score-partwise | 3.0      |
| 3.1        | 対応対象             | 対応対象       | score-partwise | 3.1      |

## 全4版共通の意味と診断

| 分類               | 表現・条件                                                                 | 結果 / 検証対象                                                     |
| ------------------ | -------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| 保持               | pitch step/alter/octaveで表せる整数MIDI音高                                | pitch0〜127、休符との区別。微分音は含めない                         |
| 保持               | duration/divisions、backup/forward、chord、rest、弱起                      | 拍のstart/duration/end、和音の同時刻、声部時刻を照合                |
| 保持               | voice、staff、part、tie start/stop                                         | パート・段・声部の独立性とタイの連続性。文字列voiceの安定対応を含む |
| 保持               | time beats/beat-type、key fifths/mode                                      | 対応可能な拍子・調号の値と適用位置                                  |
| 保持               | sound tempo、metronome beat-unit/per-minute/dots、offset                   | 四分音符換算BPMと適用時刻。soundがある場合の既存優先規則を維持      |
| 表示保持           | 対応するtype/dot/beam/stem/clef                                            | 数値正規化変更で既存表示情報を壊さない                              |
| WARNING            | lyric、print、表示上のarticulations/ornaments、和声記号の未対応表示等      | 省略する情報を示す。演奏順・音高・時刻が確定する場合に限る          |
| WARNING            | 省略された開始時tempo/meter/keyの既存既定値補完                            | 補完値を示す。不正値や不明な音高/長さの代替にしない                 |
| BLOCKING           | repeat/ending/segno/coda、soundの演奏順制御                                | 今回は展開しない。安全な候補は保存可能、練習/ゲームは禁止           |
| BLOCKING / partial | graceの時刻・長さ、unpitched、微分音、欠落pitch/duration                   | 推測で補完せず該当位置・理由を示す。表現できる不完全候補は修正可能  |
| BLOCKING / partial | 値自体は有効だが解釈不能な設定指示、パート間の時刻・拍子・調号・テンポ矛盾 | 矛盾を黙って片方へ合わせない                                        |
| 拒否               | 構文破損、不正値、成立しない参照/backup/chord、上限超過                    | 保存しない。安全な案内を返す                                        |
| 拒否               | DOCTYPEでも確定できない欠落/未知/対象外version、score-timewise、opus       | 対象の版・構造を案内し、4.0へ読み替えない                           |
| 拒否               | 内部実体・危険path・不正MXL root/展開                                      | 既存の安全性を維持                                                  |

装飾音の音高・時刻が演奏へ影響する場合は単なる表示警告としない。未認識の要素を一律WARNINGにして正常演奏とみなさず、保持対象への影響を分類する。旧版の同じ意味の表現は現行モデルで正規化し、廃止/追加された表示機能を新しい演奏機能へ広げない。

## 設定値の分類境界

- テンポ0・負数、数値であるべき設定値の非数値など、形式・値域が不正な設定値は拒否する。既定値で置き換えない。
- 値の形式・値域は有効だが演奏への適用を確定できない指示、およびパート間の設定矛盾はBLOCKINGとし、未解決のまま練習・ゲームを許可しない。安全に保持できる候補は既存の確認・保存手順で扱う。
- 開始テンポ・拍子・調号が省略され、既存の既定値で補完する場合はWARNINGとして補完値を示す。警告だけで演奏不可にはしない。

## 回帰素材の最低範囲

- 対象8組について、各版に適合した原本XMLとそのMXL、出所/利用条件/hash/期待値を記録する。
- 共通音楽内容の版間比較に加え、各版のDOCTYPEや実際の記法を公式定義に照合した例を含む。版番号の文字列置換だけでは認定しない。
- 複数声部（数値・文字列・衝突候補）、和音・休符・タイ、弱起、複数段/パート、途中の設定変更を独立期待値で確認する。
- 既存MXL16件（現在全て4.0）は旧モデルとの比較材料にし、旧版の試験件数へ水増ししない。
- unsupported-version.musicxmlの現在の3.1/4.0宣言不一致は、拒否試験として残すか名前を付け直す。真の対象外版・欠落版・未知版を別に試験する。
- Menuettは報告された原本のまま独立した検証項目とし、未入手なら未実施。保存可能でも反復等の未対応があればBLOCKINGを正しく残す。

成功判定はspecのSC-001〜006へ対応付ける。実装時に入力原本、期待値、実測と制限を記録する。

## root版欠落の限定復元

Menuett原本のようにroot版が欠落していても、rootと一致する標準Recordare PUBLIC DOCTYPEが対象版を明記する場合だけ受け入れ、MUSICXML_VERSION_FROM_DOCTYPE INFOを表示・保存する。宣言なし、SYSTEMの共通URLだけ、未知/対象外版は拒否。明示root版とPUBLIC版の矛盾も拒否。これは対象4版の範囲を拡げず、原本の明示宣言を利用する互換性方針である。
